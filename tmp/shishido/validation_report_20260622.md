## 4. 予想傾向分析

### インコース vs 外コース

| 項目 | 数値 |
|------|------|
| 1号頭予想レース数 | 18/36 (50.0%) |
| 1号頭実際レース数 | 20/36 (55.6%) |
| 外コース攻め主体予想 | 18/36 (50.0%) |

- 1号頭予想率50%は実際の55.6%よりやや低い → **外コース攻めをやや過大評価する傾向**
- ただし、外コース攻め予想時の3連単的中率も50%と高く、判定自体は的確

### 的中パターンの特徴

1. **BOX的中率69.4%が高い**: 4艇の選定精度が高く、1-3着の艇を概ね捕捉できている
2. **頭2的中率80.6%が突出**: head候補2艇のうちいずれかが1着に来る確率が非常に高い
3. **3連単→2連単のギャップ**: 3連単52.8%に対し2連単44.4%と逆転 → exacta_topの2点が狭すぎる可能性

### 不的中パターンの分析

- **びわこR2 (5-3-1)**: γ型で3号頭予想も実際は5号頭。5号がbox外で完全外れ
- **びわこR8 (6-1-2)**: β型で2号頭予想も実際は6号頭。6号はbox内だが頭予想外
- **丸亀R9 (6-1-2)**: δ型で1号頭予想も実際は6号頭。6号はbox内だが頭予想外
- **福岡R3 (3-4-5)**: δ型で1号頭予想も実際は3号頭。4,5号がbox外で完全外れ
- **福岡R8 (4-1-2)**: δ型で1号頭予想も実際は4号頭。box内だが3着5号がbox外
- **福岡R10 (4-1-6)**: δ型で1号頭予想も実際は4号頭。6号がbox内だが組み合わせ外れ

→ **6号艇の台頭を見逃すケースが散見される**（びわこR8, 丸亀R9）

## 5. Claudeの予想で特徴的だった点

### 良い点
1. **逃げ成立度の判定が的確**: 逃げ成立度が高い1号艇のレースでは高い的中率を記録
2. **A1級選手の評価が正確**: α型判定(丸亀R11,R12)は完璧に的中
3. **捲り主体の判定**: ε型で外艇を頭に据えた予想が50%的中は優秀
4. **BOX選定の安定性**: 69.4%のBOX的中率は4艇選定の精度の高さを示す

### 改善点
1. **exacta_topの点数**: 2点では的中率44.4%に留まる。3-4点に拡大を検討
2. **6号艇の過小評価**: 6号艇が1着に来るケースを見逃しがち
3. **β型の精度**: 2号直捲り判定の的中率40%は改善余地あり
4. **3着の予想精度**: BOX的中69.4%に対し3連単52.8%のギャップは3着候補の絞り込みに課題
