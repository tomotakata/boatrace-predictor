# 競艇予想AI v58.7 — ダッシュボード生成ロジック全書（出走表 → 数値）

本書は `dashgen_code.py`（決定論コード版・LLM不使用）の実装そのままを書き起こしたもの。
出走表の生データから、ダッシュボードの各数値（EI / TI / 1着率 / 着内率 / 2着期待 / 逃げ成立度 …）と
エンジン側の **cal_win** をどう計算しているかを定義する。UI は対象外。計算式のみ。

> 用語の対応
> - `first_prob` = **P1（1着率%）**
> - `place_prob` = **着内率（3着内率, Σ=300 に正規化）**
> - `second_expect` = **2着期待（Σ=100 に正規化）**
> - `ei` = 能力指数 / `ti` = 信頼指数 / `nige_success_rate` = 逃げ成立度（1号のみ）
> - `cal_win` = first_prob を当節較正・再正規化した **較正1着率**（エンジン RUN-02 で算出）

---

## 0. 全体パイプライン（出走表 → ダッシュボードJSON）

```
出走表(entries[6]) + 他艇成績(racer_courses) + 環境(environment)
  │
  ├─ ① 基準ST kijun_st
  ├─ ② 優勢順位D yusei_rank
  ├─ ③ モーター順位 motor_rank
  ├─ ④ 握り率 nigiri_rate
  ├─ ⑤ 捲り完遂力差 g  makuri_g
  ├─ ⑥ pre_EI（G除外）ei_components→ei_full → 順位 pre_rank
  ├─ ⑦ 握り発生率 hassei  nigiri_hassei（pre_rank 必要）
  ├─ ⑧ EI（G加算・最終）ei_full
  ├─ ⑨ P1（1着率）p1_calc
  ├─ ⑩ 1号被弾分析 higaki_analysis（1号イン進入時の他艇成績）
  ├─ ⑪ 減衰係数 damping_1c → P1再計算
  ├─ ⑫ 逃げ成立度 nige_seiritsu
  ├─ ⑬ TI（信頼指数）ti_1c / ti_others（P2マトリクス）
  ├─ ⑭ 着内率 place_prob・2着期待 second_expect  kachu_2nd_expect
  └─ ⑮ 捲り負け率・抵抗・連帯艇 resist_partner
  ↓
ダッシュボードJSON（各艇 indexes に格納）
  ↓（エンジン側）
  └─ RUN-02 で first_prob → cal_win に較正
```

各艇は「コース1〜6」で扱う（course）。frame は枠番（進入変更があれば course≠frame）。

## 共通定数

```
CLASS_VAL = {A1:4, A2:3, B1:2, B2:1}          # 級別の数値
SCORE_MAP = [100, 80, 60, 40, 20, 0]          # 降順スコア(1位100 … 6位0)
```

- `desc_score(values)`：値が大きいほど上位。順位 = (自分より大きい個数)+1 → SCORE_MAP に変換（同点タイ・次順位スキップ）。
- `asc_rank(values)`：小さいほど1位。順位 = (自分より小さい個数)+1。
- `_shrink(rate, n) = (rate×n + 2000) / (n + 20)`：標本数 n が小さい率を平均（2000/20 = 100% 相当）へ縮小（ベイズ的シュリンク）。
- `f_keisu1(F)`：事故F補正。F2(未未)→0.78 / F1未→0.86 / F1済→0.93 / 無→1.00。

## ⑤ 捲り完遂力差 g（makuri_g）— 外艇 c が頭(target=1号)を捲り切る力差


## ⑥ pre_EI / ⑧ EI（能力指数）— `ei_components` + `ei_full`

### 成分（各艇）`ei_components`
```
A = _shrink(コース3連率, コース出走数)             # 当該コースの3連対率（シュリンク）
B = _shrink(当地3連率, 当地出走数)
C = _shrink(一般戦3連率, 一般戦出走数)（無ければ A で代替）
D = SCORE_MAP[優勢順位D−1]                          # ST優勢のスコア化
F = 出足desc×0.45 + 伸び足desc×0.55                 # モーター（季節モーター時は×0.85）
G = 0（1号） / それ以外 = min(握り率×0.45 + 握り発生率×0.55, 90)   # 攻め力
H = 級別/年齢: A1→95 / A2→75 / B1→55 / B2は(年齢≤30→45, それ以外→40)
```
重み `EI_W = {A:1.05, B:0.95, C:0.85, D:1.55, F:1.65, G:1.20, H:0.90}`。

### 最終 `ei_full`
各艇 `per(i, include_g)`：
```
base = Σ(成分×EI_W) / Σ(EI_W)     # include_g=False が pre_EI、True が最終EI
J = [1.08,1.04,1.02,1.00,0.95,0.89][コース]          # コース係数
K = clip(1 − (今節着順−1)×0.04, 0.80, 1.00)          # 着順安定
L = f_keisu1(F) × f_keisu3(F,ST乖離)                  # 事故F補正（系統1×系統3）
N = 当地補正（当地3連率/コース3連率 を 0.75〜1.30 にクリップ。当地出走<5は1.00、≤9は半量ブレンド）
prod = min(J×K×L×N, 1.30)
I  = 級別×枠の枠補正テーブル（例 A1の4枠 −4 / B1の1枠 +12 …）
Il = 地元(愛知)かつ当地出走≥10 で +5
M  = 4-6号 かつ 伸び足desc≥60 かつ 握り発生率≥10 のとき {3号:6,4号:6,5号:8}
EI = round(base×prod + I + Il + M)
```
- pre_EI（G除外）の降順順位 `pre_rank` を握り発生率⑦に渡す。
- 最終EI（G加算）= ダッシュの `ei`、降順順位 = `ei_order`。

## ⑦ 握り発生率 hassei（nigiri_hassei）— 各外艇が握って攻めに行く率

```
2号: H[2] = (握り率2/100) × _stdom(base2−base1) × w × 100 × core_mult[2]
3号: 2段階連鎖。
     hikinami = 1 − (2号差し率%/100)×0.3            # 2号が差すと3号は引き波回避できる
     hA = (握り率3/100)×_stdom(base3−base2)×1.20     # 2号が握った世界

     nig2 = H[2]/100
     H[3] = (hA×nig2 + hB×(1−nig2)) × w × 100 × core_mult[3]
4号: スリット絞り。
     shibori = {pre_rank4: 1→1.00,2→0.85,3→0.70,他→0.55}
     kabe = 2号の pre_rank と base_st で 0.75〜1.30（2号が速い壁なら抑制、遅い壁なら増幅）
     tenkai = (H2+H3>40→1.15 / ≥20→1.00 / 未満→0.85)
     H[4] = _stdom(base4−base3, 4号スケール)×shibori×kabe×tenkai×w×0.90×100×core_mult[4]
5・6号:
     hakka = ΔST(base_c − base_{c-1}) の段階値（≤−0.04→0.85 … >0→0.05）
     teki  = min(握り率/30, 1)（出走≥5、未満は0.50）
     antei = 1 − (今節着順−1)×0.05
     H[c]  = hakka×teki×antei×f_keisu1(F)×0.90×w×100×core_mult[c+1]
```

## ⑨ P1（1着率%）— `p1_calc`★買い目直結

## ⑩ 1号被弾分析（higaki_analysis）— 1号イン進入時に他艇がどれだけ食うか

入力：`racer_courses[1].others[c]`（1号がインのとき各外艇 c の成績）。
```
各 c=2..6:
  hit   = 他艇1着率（被弾率）
  hit2r = 他艇2連率
  main  = 決め手（差/捲/捲差 の最大）
  乗艇係数 coef = EI偏差(ei/base_ei)×0.5 + 勝率偏差(勝率/base_wr)×0.3 + モーター偏差MOT_DEV×0.2
       × 決め手×コースの相性補正（4号の捲×1.20 / 3号の捲差×1.12 / 5号の捲差×1.08 / 2号の差×1.05）
       × 季節（夏×1.10 for 3,4号） × R帯（1-4Rの3,4号×1.15 / 12Rの3,4号×0.85, use_rnum時）
       × 地元×1.05
       coef = clip(coef, 0.50, rider_max)
  nin = min(1号出走数/15, 1)                         # 標本信頼度
  補正被弾 hit_adj  = hit  × coef × nin
  補正2連 hit2r_adj = hit2r × √coef × nin
```

## ⑫ 逃げ成立度（nige_seiritsu）= ダッシュの `nige_success_rate`（1号）

外艇の「攻め圧力」を積み上げ、1から引いて1号の逃げ成立度を出す。
```
nin = min(1号出走数/15, 1)
（各 c=3,4,5,6 のカド攻め）
  h2adj  = hit2r(c) × √乗艇係数(c) × nin
  threat = (h2adj≥30 → 1.15, 他1.00)
  成立   = g[c] × kado[c] × threat                  # g=⑤捲り完遂力差, kado=会場カド係数
  ap_nig += (握り発生率[c]/100) × 成立
ap_nig += (握り発生率[2]/100) × 1.00                  # 2号の差し/まくり圧

場固有脅威 ba：4号(捲・補正被弾≥10)+0.20 / 3号(捲)+0.10 / 5号(捲差)+0.06 / 2号(差)+0.08 …（段階加算）+0.02
条件 cond：1-4R +0.06 / 夏 +0.03
ap = ap_nig + (ba + cond)
逃げ成立度 nige = clip(1 − min(ap×0.5, 0.85), 下限floor, 0.85)   # 下限は会場 nige_floor（R帯 or 季節）
```

### 1号 TI
```

```
（コース基準1C勝率 = 会場 `base_1c_wr`、季節キー対応）

### 2〜6号 TI（P2マトリクスから）
P2[i|j] = 「j号が1着のとき i号が2着に来る率」。
```
他艇列: P2[i|j] = 他艇2連率 − 他艇1着率（racer_courses[i].others[j] から）
1号列 : P2[i|1] = 被弾分析 hit2r(i) − hit(i)

```
TI順位 = TI の降順順位。

## ⑭ 着内率（place_prob, Σ=300）/ 2着期待（second_expect, Σ=100）— `kachu_2nd_expect`

### 着内率（3着内に入る率）
```
w3(i) = 加重3連率（コース3連率×当地3連率のブレンド。当地<5はコースのみ、≤9は60:40、≥10は40:60）
ability[i] = clip(0.80 + 0.40×EI/100, 0.80, 1.25)
（上流攻めの恩恵 up：内側の握り発生率を距離重み w={1差:1.0,2差:0.8,3差:0.6,4差:0.5} と exploit_kado で加重和。
  2号は差し主体補正で hj を差し率ベースに底上げ）
exploit = 0.5 + 0.5×EI/100
benefit = 1 + k_b × (up/100) × exploit
raw[i] :
  1号 = 残存(=w3[0]) × (0.95+0.05×EI/100) × (1 − 崩壊率houkai×0.4)
        houkai = 4号/3号の補正2連率(hit2r_adj)の大きい方（1号が崩される率）
  他  = w3[i] × ability[i] × benefit
着内率 place_prob[i] = min( raw[i] × 300 / Σraw, 99 )         # Σ=300 に正規化、各艇99%上限
```

### 2着期待（2着に来る期待の配分）
```
1号: 純2着率 = 2連率 − 1着率、3着保険 = (3連率−2連率)×0.3
     e2[1] = max(純2着率,0) + max(3着保険,0)
他 : 純2着率 = max(2連率 − 1着率, 0)
     drive  = TI × EI / 100                          # 自力で上位に来る寄与
     e2[i]  = 純2着率 + drive×0.5（0なら 3連率×0.15 で僅かに付与）
2着期待 second_expect[i] = e2[i] / Σe2 × 100           # Σ=100 に正規化
```

## cal_win とは（エンジン RUN-02 `_run02_calibrate`）★

ダッシュの `first_prob`(P1) を **当節較正して再正規化した「較正1着率%」**。買い目ロジックは P1 ではなく cal_win を勝率の正本として使う。

```
1) 出発点: cal = first_prob（各コース）
2) 当節較正（venue_calibration がある場合のみ）:
     実1号頭率 R、場平均 P0、標本N が与えられ、N ≥ N_CAL のとき
       R < P0 − DEC2_GAP → 1号に DEC2 を乗算（強い減衰）
       R < P0 − DEC1_GAP → 1号に DEC1 を乗算（弱い減衰）
     減衰で減った分 delta を、他コースへ first_prob 比で再配分（合計保存）
3) 正規化: cal_win = cal / Σcal × 100
4) 改正74 外枠A級補正: 5/6号がA級で相対的に強いとき _outer_agrade_boost を加点 → 再正規化（合計100%維持）
5) gap = cal_win最大 / 2番手（頭の抜け具合。僅差判定に使用）
6) 1号非信用 distrust_1 = (cal_win[1] < DISTRUST_WIN%) または (当該コース実勝率0% かつ 出走≥2)
```
- venue_calibration が無ければ較正はかけず、first_prob をそのまま正規化（prior据え置き）。
- `cal_nige` = ダッシュの逃げ成立度（1号）をそのまま採用。
- 改正76：この後、1号の「2着内粘り」を着内率ベースで second_expect に底上げ（頭を失っても差され残り/連れ上がりで2-3着に残る分）。

> まとめ：**P1(first_prob)＝出走表データから出した素の1着率**、**cal_win＝それを当節の実頭率と外枠A級で較正し合計100%に正規化した、買い目用の最終1着率**。

## 決定論性（同じ入力なら必ず同じ数値）

本生成器は乱数・時刻・ハッシュ依存を一切使わない。順位付け（desc_score/asc_rank）も
同点は「自分より上の個数+1」で一意に決まり、ソートは安定。よって **同じ出走表からは毎回同一のダッシュボード** が出る。
（LLM版 `dashgen_llm.py` を経由した場合のみ非決定。アプリは r255 以降コード版に固定。）
