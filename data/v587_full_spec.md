# 競艇予想AI v58.7（Build r113-format-by-class） 買い目生成 全計算式

このドキュメントは「サイトで実際に行っている、出走データから買い目を出すまでの全計算」を、省略・短縮なしで書き起こしたものです。
処理は2つのファイルに分かれます。

- **dashgen_code.py** … 出走データ → ダッシュボード（各艇の指標）を生成（段階1の前半「$0生成」）
- **engine/v58_7_engine.py** … ダッシュボード → 展開・候補買い目（run_analysis）→ オッズ反映・最終買い目（apply_return_gate）

────────────────────────────────────────

## 0. 全体フロー（2段階）

**段階1：生成＆展開ロック（$0・AI不要）**
1. 公式サイト等から出走データ・直前情報を取得（フェッチ／パース）
2. `build_dashboard()` が各艇の指標を計算（EI・TI・1着確率・逃げ成立度・着内確率・2着期待 など）
3. `run_analysis()` がダッシュボードを読み、攻め主体・頭・本線12点・2連単候補・スイチ候補・万舟プール・①②③④フォーマットを確定（＝展開ロック）

**段階2：オッズ取得＆最終買い目**
4. 公式オッズ（3連単・2連単の全盤面）を取得
5. `apply_return_gate()` が本線の合成オッズを計算 → レース分類（見送り／通常／勝負）→ 各賭式の配分（買い目金額）を確定

# 第I部　ダッシュボード生成（dashgen_code.py）

各艇 i（コース 1〜6、index は 0〜5）について最終的に次を出力する。

- `indexes.ei`（EI＝期待指数）, `ei_order`（EI順位）
- `indexes.ti`（TI指数）, `ti_order`（TI順位）
- `indexes.first_prob`（1着確率 P1, %）
- `indexes.nige_success_rate`（逃げ成立度。1号のみ。0〜1）
- `indexes.place_prob`（着内確率 P_top3, %。6艇合計≒300）
- `indexes.second_expect`（2着期待, %。6艇合計≒100）
- `attack_profile.nigiri_rate`（握り率, %）, `occurrence_rate`（握り発生率, %）
- `start.base_st`（基準ST）, `advantage_order`（優勢順位D）
- `motor.rank`（S/A/B/C/D）, `rank_order`

会場ごとに係数が異なる（VENUES辞書）。主なキー：
- `mot_w`＝(出足重み, 伸び足重み) … 捲り完遂力差gのモーター項配分
- `kado`＝カド係数{コース:係数} … 逃げ成立度の攻め圧力
- `exploit_kado`＝受益係数{コース:係数} … 着内確率の上流受益
- `k_b` … 着内確率の受益スケール
- `core_mult`＝核補正{コース:係数} … 握り発生率
- `nige_floor` … 逃げ成立度の下限（`floor_basis`が"rnum"ならR帯別、"season"なら季節別）
- `use_rnum` … P1・被弾でR番号補正を使うか
- `base_ei`,`base_wr`,`base_1c_wr`,`rider_max` … 被弾分析の基準
未登録会場は蒲郡設定をベースに使う。

## I-1. 共通の補助関数

**desc_score（降順スコア）**：値が大きいほど上位。競技順位（同点タイ・次順位スキップ）を出し、順位1〜6位に `SCORE_MAP[rank-1]`（=100, 80, … と並ぶ配点）を与える。
```
rank(v) = (vより大きい値の個数) + 1
score(v) = SCORE_MAP[min(rank-1, 5)]
```

**asc_rank（昇順順位）**：小さいほど1位。`rank(v) = (vより小さい値の個数)+1`（同点タイ）。

**f_keisu1（事故F補正・系統1）**：直前情報のF表記から
```
"F2"を含む → 0.78
"F1未"     → 0.86
"F1"       → 0.93
それ以外   → 1.00
```

## I-2. Stage1（基礎値）

### 基準ST（base_st） — `kijun_st`
各艇の平均ST a、コース別平均ST c（無ければa）、今節ST n（無ければa）から
```
初日・2日目 : base_st = a×0.5 + c×0.5
3日目以降   : base_st = a×0.4 + c×0.3 + n×0.3
```

### 優勢順位D（advantage_order） — `yusei_rank`
今節ST順位 r_cur、平均ST順位 r_avg（いずれも asc_rank）、今節着順 cur_ord から生スコア
```
s = r_cur×0.40 + r_avg×0.35 + cur_ord×0.25
s = s × (1 − (cur_ord − 1)×0.05)          … 安定補正
s = s × f_keisu1(F表記)                    … 事故F補正
優勢順位D = asc_rank(s)                     … 小さいほど上位
```

### 捲り完遂力差 g（攻め成立係数） — `makuri_g`（target=1号に対して）
出足・伸び足を desc_score 化（de, no）。会場の (dw, nw)=mot_w で
```
mscore[i] = de[i]×dw + no[i]×nw
各コース c（2〜6, index i=c−1, 対象 t=0=1号）について
  st  = (base_st[t] − base_st[i]) / 0.03          … STで上回る分
  mot = (mscore[i] − mscore[t]) / 100             … モーターで上回る分
  cls = (級数値[i] − 級数値[t]) / 3                … 級で上回る分（CLASS_VAL）
  diff = 0.40×st + 0.35×mot + 0.25×cls
  g[c] = clamp(0.5 + diff, 0.0, 1.30)             … 下限0／上限1.30
```

### 握り率（nigiri_rate, %）
1号は None。他艇は出走数 n が5以上なら
```
握り率 = (捲り勝ち + 捲差勝ち) / n × 100
n<5 → 50.0 固定
```

### モーター順位（motor_rank）
```
合計 = 出足 + 伸び足
順位 = 合計の降順（大きいほど1位）
ランク：≧11→S / 9〜10→A / 8→B / 6〜7→C / ≦5→D
```

## I-3. Stage2 握り発生率（occurrence_rate, %） — `nigiri_hassei`

平均ST `avg=Σbase_st/6`、風補正 w（`_wind_hassei`：追い風5m超1.20 / 追い風3-4m1.10 / 向かい風3m以上1.15 / 向かい風1-2m1.05 / 横風・無風0.95）。
ST優勢度 `_stdom(Δ)`（Δ=base_st差。Δ≦-0.04→1.00 / ≦-0.02→0.80 / ≦0→0.55 / ≦0.02→0.25 / それ以上→0.05。4号専用 scale4 は別スケール）。
会場核補正 cm=core_mult。1号は None。

**2号**
```
H[2号] = 握り率2/100 × _stdom(base_st2 − base_st1) × w × 100 × cm[2]
```
**3号（2段階連鎖：2号が握った世界 hA と握らない世界 hB の加重）**
```
nig2 = H[2号]/100
hikinami = 1 − (2号の差し率)×0.3        （= 引き波の効きづらさ）
hA = 握り率3/100 × _stdom(base_st3 − base_st2) × 1.20
hB = 握り率3/100 × _stdom(base_st3 − base_st1) × hikinami
H[3号] = (hA×nig2 + hB×(1−nig2)) × w × 100 × cm[3]
```
**4号（スリット絞り）**
```
shibori = pre_EI順位4が 1→1.00 / 2→0.85 / 3→0.70 / その他→0.55
壁(kabe)：2号の pre_EI順位 r2 と base_st b2、avg から
  r2=1 かつ b2≤avg−0.02 → 0.75
  r2∈{2,3}              → 1.00
  r2∈{4,5} または b2>avg+0.02 → 1.15
  r2=6 かつ b2>avg+0.04  → 1.30
  それ以外              → 1.00
s23 = H[2号]+H[3号];  tenkai = s23>40→1.15 / ≥20→1.00 / それ未満→0.85
H[4号] = _stdom(base_st4−base_st3, scale4) × shibori × kabe × tenkai × w × 0.90 × 100 × cm[4]
```
**5・6号**（c=4,5 の index。前艇との差 d=base_st[c]−base_st[c−1]）
```
hakka(発火) = d≤-0.04→0.85 / ≤-0.03→0.70 / ≤-0.02→0.55 / ≤-0.01→0.40 / ≤0→0.25 / それ以上→0.05
teki(適性) = 出走数≥5 なら min(握り率/30, 1)、未満なら 0.50
antei(安定) = 1 − (今節着順−1)×0.05
H[c] = hakka × teki × antei × f_keisu1 × 0.90 × w × 100 × cm[c+1]
```

## I-4. Stage3 EI（期待指数）

成分 A〜H（`ei_components`）。`_shrink(rate, n) = (rate×n + 2000)/(n + 20)`（標本縮約）。
```
A = _shrink(コース別3連率, コース別出走数)
B = _shrink(当地3連率, 当地出走数)
C = _shrink(一般戦3連率, 一般戦出走数)（無ければ A で代替）
D = SCORE_MAP[優勢順位D − 1]
F = 出足desc×0.45 + 伸びdesc×0.55 （季節モーターなら ×0.85）
G = （1号は0）他艇は min(握り率×0.45 + 握り発生率×0.55, 90.0)
H = 級が A1→95 / A2→75 / B1→55、それ以外は 年齢≤30→45 / それ超→40
```
重み `EI_W = {A:1.05, B:0.95, C:0.85, D:1.55, F:1.65, G:1.20, H:0.90}`。

最終EI（`ei_full`。pre_EI は G を除外して算出し、その順位を握り発生率に渡す。EI_final は G を加算）：
```
keys = [A,B,C,D,F,H]（pre_EIはGなし／finalはG追加）
base = Σ(成分×EI_W) / Σ(EI_W)
J（枠補正）= [1.08, 1.04, 1.02, 1.00, 0.95, 0.89][コースindex]
K = clamp(1 − (今節着順−1)×0.04, 0.80, 1.00)
L = f_keisu1 × f_keisu3
  f_keisu3（F萎縮・系統3）：f_keisu1=1.00なら1.00、そうでなければ今節STと基準STの差 d で
    d≥0.05→0.70 / ≥0.03→0.80 / ≥0.01→0.90 / ≥-0.01→0.95 / それ未満→1.00
N（当地適性）= 当地出走<5→1.00、そうでなければ raw=当地3連率/コース別3連率を
    出走≤9 は 1+(raw−1)×0.5、10以上は raw。最後に clamp(0.75, 1.30)
prod = min(J×K×L×N, 1.30)
I（級×枠の固定補正）= 例 (A1,4)→-4, (A1,5)→-10, (A1,6)→-12, (A2,1)→+10, (A2,2)→+6,
    (A2,5)→-6, (A2,6)→-8, (B1,1)→+12, (B1,2)→+8, (B1,5)→-4, (B1,6)→-6, (B2,1)→+10, (B2,2)→+10、他0
Il（地元愛知 かつ 当地出走≥10）= +5、他0
M（外伸び）= index≥3 かつ 伸びdesc≥60 かつ 握り発生率≥10 のとき {3号:+6, 4号:+6, 5号:+8}、他0
EI = round(base×prod + I + Il + M)
EI順位 = EIの降順（大きいほど1位）
```

## I-5. Stage4 P1（1着確率 first_prob, %） — `p1_calc`

```
avg = Σbase_st/6;  season=季節係数表;  band=R帯;  rnum=R番号係数表（use_rnum時のみ）
モーター乗算 mot_m = S:1.10 / A:1.10 / B:1.05 / C:1.00 / D:0.90
減衰係数 genshu1（1号のみ。下で被弾分析→damping_1cから。無ければR帯下限GENSHU_FLOOR）

p1raw(i) = 当地出走<5 → コース別勝率
           当地出走≤9 → コース別勝率×0.6 + 当地勝率×0.4
           当地出走≥10 → コース別勝率×0.4 + 当地勝率×0.6
ST補正 _st_hosei(d=base_st[i]−avg) = d≤-0.03→1.15 / ≤-0.01→1.08 / <0.01→1.00 / <0.03→0.90 / それ以上→0.78
左隣補正 _hidari（1号は1.00。他は前艇のd） = d≤-0.03→1.05 / ≤-0.01→1.02 / <0.02→1.00 / それ以上→0.97

pre[i] = p1raw × g × _st_hosei × _hidari × mot_m × dte(=1.00) × season[コース]
         × wind_mult × rnum[コース] × wave_mult
         （g は1号のみ genshu1、他は1.0）
P1[i] = pre[i] / Σpre × 100
```
季節係数 SEASON・R番号係数 RNUM・下限 GENSHU_FLOOR は会場（§9）の核。例（蒲郡）：
- SEASON summer={1:0.92,2:1.10,3:1.15,4:1.18,5:0.95,6:0.90}, autumn={1:1.18,…,6:0.80}, winter={1:1.05,…}, spring=全1.00
- RNUM "1-4"={1:0.82,3:1.10,4:1.15} / "12"={1:1.30,3:0.90,4:0.90,5:0.85,6:0.80} など
- GENSHU_FLOOR "1-4":0.62 / "12":0.85 / normal:0.70 など

## I-6. Stage5-6 被弾分析・減衰・逃げ成立度・TI

### 被弾分析（1号イン進入時の他艇成績） — `higaki_analysis`
他艇 c（2〜6）について。出走補正 `nin=min(1号出走/15, 1)`。
```
hit  = 他艇1着率;  hit2r = 他艇2連率
主決め手 main = 差/捲/捲差 のうち最大のもの
乗艇係数 coef = (EI偏差)×0.5 + (勝率偏差)×0.3 + (モーター偏差)×0.2
  EI偏差 = EI[c]/base_ei[c]、勝率偏差 = コース別勝率[c]/base_wr[c]、モーター偏差 MOT_DEV(S/A:1.15,B:1.05,C:0.95,D:0.80)
決め手・季節・R帯・地元の乗算（例：4号で"捲"→×1.20 / 3号"捲差"→×1.12 / 5号"捲差"→×1.08 / 2号"差"→×1.05、
  夏かつ3・4号→×1.10、use_rnum&"1-4"&3・4号→×1.15、"12"&3・4号→×0.85、地元→×1.05）
coef = clamp(coef, 0.50, rider_max)
hit_adj   = hit × coef × nin           … 補正被弾（1号の減衰に使用）
hit2r_adj = hit2r × √coef × nin        … 補正被弾2連
```

### 減衰係数（1号） — `damping_1c`
```
s = Σ(hit_adj)（他艇分の合計）
g = 1 − (s/100)×0.5
減衰係数 = max(g, R帯下限GENSHU_FLOOR)        （= 上の P1 の genshu1）
```

### P2列（1号が勝った時に各コースが2着に来る率） — `p2_column_from_1c`
```
P2[c | 1号] = 他艇2連率 − 他艇1着率
```
（2〜6号が勝つ世界の P2 は、各艇の他艇成績から同様に `他艇2連率 − 他艇1着率` で P2マトリクスを作る）

### 逃げ成立度（nige_success_rate, 0〜1） — `nige_seiritsu`
```
nin = min(1号出走/15, 1);  kado = 会場のカド係数{3,4,5,6}
攻め圧力（握り由来）ap_nig：
  各 c∈{3,4,5,6}：
    h2adj = (他艇2連率) × √(乗艇係数) × nin
    threat = h2adj≥30 → 1.15、それ未満 → 1.00
    seiritsu = g[c] × kado[c] × threat        （g[c]＝捲り完遂力差）
    ap_nig += (握り発生率[c]/100) × seiritsu
  ap_nig += (握り発生率[2号]/100) × 1.00
場固有脅威 ba（決め手・補正被弾で加算）：
  4号: hit_adj≥10&"捲"→+0.20 / ≥5→+0.10 / 他+0.03
  3号: hit_adj≥10&"捲"→+0.10 / ≥5→+0.06 / 他+0.02
  5号: hit_adj≥10&"捲差"→+0.06 / 他+0.02
  2号: hit_adj≥10&"差"→+0.08 / ≥5→+0.04 / 他+0.02
  +0.02（ベース）
条件加算 cond：R帯"1-4"→+0.06、夏→+0.03
脅威合計 threat_total = ba + cond
ap = ap_nig + threat_total
逃げ成立度 nige = clamp( 1 − min(ap×0.5, 0.85), 下限floor, 0.85 )、最後に max(nige, 0.15)
  floor は floor_basis に従い R帯別 or 季節別の nige_floor
```

### TI指数 — `ti_1c` / `ti_others`
```
1号 TI_raw = 逃げ成立度 × 100 × (P1_raw_1号 / コース基準1C勝率) × min(1号出走/20, 1)
2〜6号 TI_raw = Σ_j ( P1[j] × P2[i|j] ) × min(出走/20, 1)     （P1[j]は小数。合計1）
TI順位 = TIの降順（大きいほど1位）
```

## I-7. Stage7 着内確率（place_prob）・2着期待（second_expect） — `kachu_2nd_expect`

会場の `k_b`（受益スケール）, `exploit_kado`（受益係数）。
```
加重3連率 w3(i)：当地出走<5→コース別3連率 / ≤9→コース別×0.6+当地×0.4 / ≥10→コース別×0.4+当地×0.6
能力 ability[i] = clamp(0.80 + 0.40×EI[i]/100, 0.80, 1.25)
上流受益 up[i]（iより内のj=0..i-1から）：
  for j<i: hj=握り発生率[j]（2号は差し主体補正 max(hj, 差し率/出走×100×0.5)）
           kg=exploit_kado[j+1]
           重み w(距離)=｛隣1:1.0, 2:0.8, 3:0.6, 4:0.5｝
           up += hj × w(i−j) × kg
exploit = 0.5 + 0.5×EI[i]/100
benefit = 1 + k_b × (up/100) × exploit
raw[i] = （1号）survival × (0.95 + 0.05×EI/100) × (1 − houkai×0.4)
         （他艇）w3[i] × ability[i] × benefit
着内確率 place_prob[i] = min( raw[i] × 300 / Σraw, 99 )      （6艇合計≒300）

2着期待 second_expect：
  1号 e2[0] = ( (2連率−勝率)×0.7 + (3連率−2連率)×0.3 ) × (1−逃げ成立度) + (2連率−勝率)×0.3
  他艇 pure2 = max(2連率 − 勝率, 0)            （純2着率）
       drive = TI[i] × EI[i] / 100             （自力上位寄与）
       val   = pure2 + drive×0.5
       e2[i] = val>0 ? val : 3連率×0.15         （全0でも着内があれば僅かに）
  second_expect[i] = e2[i] / Σe2 × 100          （6艇合計≒100）
```

## I-8. build_dashboard の計算順序

```
1. base_st（基準ST）
2. 優勢順位D、モーター順位、握り率、捲り完遂力差g
3. pre_EI（G除外）→ pre_EI順位
4. 握り発生率（pre_EI順位を使用）
5. EI_final（Gを加算）→ EI順位
6. P1（暫定 genshu1=下限）
7. 被弾分析 → 減衰係数 genshu → P1を再計算（genshu反映）
8. 逃げ成立度（g・握り発生率・被弾分析から）
9. 1号TI → P2マトリクス → 2〜6号TI → TI順位
10. 着内確率・2着期待
11. 各艇の indexes に格納してダッシュボードJSONを返す
```

# 第II部　買い目エンジン run_analysis（ダッシュボード→展開・候補）

## II-0. 定数 TH（しきい値・全件）

```
ALPHA_WIN=50.0          α: 1号較正後1着率
GAP=1.6                 GAP差（1位/2位）
NIGE_TOTSU=0.80         逃げ成立度突出（α）
BETA_WIN=38.0           1号<38%でだけ2号直捲りを本線頭に
EPS_NIGE=0.50           ε: 1号逃げ成立度<50%
直捲り発火ゲート：
  MAKURI_NIGE_SAFE=0.55     1号逃げ成立度がこれ以上→守り堅い
```

## II-3. RUN-02 逃げ成立度較正・1着確率の再正規化・1号非信用

# 第III部　最終買い目 apply_return_gate（オッズ→分類→配分）

## III-1. 配分の基本式 `_allocate`（メリハリなし＝オッズ反比例・戻り均一）
買い目集合と各目のオッズ o から：
```
S = Σ(1/o)                 （オッズのある目だけ）
合成オッズ = 1/S
戻り(期待) = 予算 × 合成オッズ
各目の配分 alloc[c] = round( 予算 × (1/o) / S / 100 ) × 100   （100円単位）
```
＝どの目が当たっても戻りがほぼ同じになるオッズ反比例配分。

## III-2. 本線とレース分類
```
本線12点の合成オッズ co = _allocate(本線, 3連単オッズ, 14000).合成オッズ
co<2.5  → 見送り（参加≤6,000：スイチ6,000のみ。本線は参考表示。万舟停止）
2.5〜4.0 → 通常 （参加≤20,000：本線14,000 + 2連単6,000。万舟停止）
co>4.0  → 勝負 （参加≤20,000：本線14,000 + 万舟6,000。2連単なし）
co無し  → 判定不能
```

## III-3. 通常レースの2連単（濃厚2点・確率比配分）
```
候補 = exacta_top の上位2点
配分（スコア比）：1点なら全額。2点なら
  a0 = clamp( round(6000 × score0/Σscore /100)×100, 100, 5900 )
  alloc = {目0:a0, 目1:6000−a0}
合成オッズ・戻りは配分に即して算出（来る目で戻りが違うので最低〜最高を表示。見出しは最低保証）：
  各目 ret = round(alloc×オッズ)、合成 = ret/総額。最低retを「戻り額」、最低合成を「合成オッズ」に表示。
```
見送り・勝負では2連単は出さない。

## III-4. 見送りレースのスイチ（濃厚2点・確率比配分）
```
候補 = suichi の上位2点
配分は2連単と同じ確率比（1点なら全額、2点なら a0=clamp(round(6000×score0/Σscore/100)×100,100,5900), 残りを他点）
合成オッズは表示しない（確率で選ぶ賭式のため None）
```
